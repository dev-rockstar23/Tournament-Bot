FEAT-006: Tournament Finalization and Winner System
====================================================
Status: COMPLETE
Date: 2026

## Files Created

### API Routes
1. apps/web/src/app/api/servers/[guildId]/tournaments/[tournamentId]/finalize/route.ts
   - POST, protected with withPermission(AppRole.TOURNAMENT_MANAGER)
   - Guard checks: all matches in terminal status, no open/under-review disputes
   - Computes final standings via computeTournamentStandings(prisma, tournamentId, guildId)
   - $transaction: creates WinnerRecord (top 3), Award records (Champion + Top Fragger),
     locks results (resultsLocked=true), transitions status to COMPLETED,
     creates OutboxEvent(TOURNAMENT_COMPLETED)
   - Writes AuditLog(TOURNAMENT_FINALIZED) outside transaction
   - Returns { winners, standings }

2. apps/web/src/app/api/servers/[guildId]/tournaments/[tournamentId]/winners/route.ts
   - GET, public (no auth)
   - Scoped by guildId AND tournamentId
   - Returns non-superseded WinnerRecord entries with team info
   - Never exposes PENDING registrations or private data
