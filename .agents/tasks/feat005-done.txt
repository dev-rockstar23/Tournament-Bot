   POST — withPermission(PLAYER). Validates body with ResultSubmitSchema (zod).

   validates captain-of-participant OR REFEREE+ authorization, validates all scorecardJson

2. apps/web/src/app/api/servers/[guildId]/matches/[matchId]/approve/route.ts
   POST — withPermission(REFEREE). Body: { action: 'approve'|'reject', reason?: string }.
   Approve path ($transaction): fetches match+tournament+ruleVersion, validates UNDER_REVIEW,
   gets PENDING_REVIEW submission, parses scorecardJson, builds ScoringConfig (ruleVersion or
   game default), calls calculateBgmiMatchScore (generic signature across all games), creates
   ScoreEvent records (Decimal points/penalties), sets submission APPROVED+reviewedBy+reviewedAt,
   assertMatchTransition(→COMPLETED), creates OutboxEvent(RESULT_APPROVED), writes AuditLog.
   Reject path: validates UNDER_REVIEW, sets submission REJECTED+reason, assertMatchTransition
   (→AWAITING_RESULT), creates OutboxEvent(RESULT_REJECTED), writes AuditLog.

   In $transaction: fetches match (guildId-scoped), creates Dispute(status:OPEN),
   assertMatchTransition(→DISPUTED), updates match, creates OutboxEvent(DISPUTE_OPENED),
   writes AuditLog.
